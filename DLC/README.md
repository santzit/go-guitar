# DLC Directory

Place your Guitar Pro song files here:

- `*.gp`  — Guitar Pro (auto-detect version)
- `*.gp3` — Guitar Pro 3
- `*.gp4` — Guitar Pro 4
- `*.gp5` — Guitar Pro 5

The game will list every file found in this folder on the **Song Select** screen.

## Getting GP files

- Export tabs from **Guitar Pro** or **TuxGuitar** (free, open-source).
- Download from public tab sites such as **Ultimate Guitar** (`.gp5` / `.gpx`).
- Convert MIDI to GP format with TuxGuitar.

> **Note:** This directory ships empty.  No copyrighted tabs are included.
